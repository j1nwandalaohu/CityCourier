# 行人和车辆悬空修复

原因是生成时从上方 500cm 做 `WorldStatic` 通道射线。通道检测会命中阻挡该通道的动态车辆和行人，也可能命中高处雨棚。移动逻辑随后只更新 XY，永久保留了错误的生成 Z，后续生成还会叠在先生成的人车碰撞盒上。

修复使用静态物体类型检测，以道路节点高度初始化，随后跟踪实际路面高度。向上 35cm、向下 80cm 的检测区间排除高处屋顶和雨棚，忽略动态人车；中心和碰撞占地四角均检查支撑。沿小路缘调整高度，缺少支撑时停止移动或禁用该实例，避免继续在空中运行。生成位置的阻挡检测放在贴地之后。
