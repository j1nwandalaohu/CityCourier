# 汽车两段攀跳与随车移动

从汽车前方朝车身移动并按空格，先落到引擎盖；站稳后再次跳跃，落到车顶。站在引擎盖或车顶可以随车辆前进和转弯，也可以走动或跳下。

## 碰撞与物理

- 保留原有交通/场景碰撞盒；角色改用独立车身、引擎盖和车顶碰撞面，分别对齐模型的 100cm、115cm、167cm 高度。
- 沿用普通跳跃的 420cm/s 初速度（约 90cm 高）。仅在车头前方、面对且靠近汽车时，根据引擎盖高度临时提供最高 520cm/s 的起跳助力；起跳后立即还原设置。
- 头顶空间、界面状态、空中禁止二段跳和落地短暂保护仍由原有角色逻辑检查。
- 使用原生 CharacterMovement 移动基座承载人物，保持可走动、转向、跳下；不将角色硬绑在车身上。
- 只在交通避障查询中忽略已站在本车上的角色，车前普通行人仍会让车辆停车。
- 为手动驱动的碰撞面更新实际分量速度，跳下时继承车辆动量。对象池重置或隐藏时清零速度，避免把回收瞬移当成行驶速度。
- 行人禁用车辆专用碰撞面，并保留原来的行人阻挡。
