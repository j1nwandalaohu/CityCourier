## 审查结论与处理

无 Critical。以下三项 Important 均维持等级，纳入一次修复过程：

1. **静态障碍下仍可接单。** 预览拒绝的道路仍能出现在候选中并开始计时。增加 `FunctionalUpgrade.Review.BlockedOffers`，验证候选筛选、实际控制器提示与配送底层接口拒绝，且移除障碍后恢复。
2. **未来外层格式触发旧备份回退。** `CPR3` 被当成一般损坏，导致较新主文件被移走并自动恢复旧备份。增加 `FunctionalUpgrade.Review.FutureEnvelope`，验证不自动写入、不移动主文件、两份存档逐字节保留、不生成损坏标记。
3. **车辆离道路数米时的到达误判。** 玩家距车约 1.55 米，往返道路连接段却报约 11.6 米。增加 `FunctionalUpgrade.Review.OffRoadBikeArrival`，覆盖同侧接近、车旁、范围外与阻挡短连接，避免绕路进度掩盖实际到达。

三项测试在 `Automation-20261018-132516-86c1e32f` 均观察到预期断言失败；修复后 `Automation-20261018-132732-410bb762` 全套 51/51，加入实际未来格式存档检查后 `Automation-20261018-132930-2798bf8a` 仍为 51/51。修复提交 `554d8f5`，没有再次派发审查；更新包结果见 [验证记录](function-improvements-validation.md)。
