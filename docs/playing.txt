街头骑手 / 南城 — Windows 首版

双击同目录 CityCourier.exe 开始。复制游戏时请保留整个目录，不能只复制 exe。
首次在其他电脑运行，若提示缺少 Visual C++ 运行库，可运行 Engine\Extras\Redist\en-us\vc_redist.x64.exe。

第一单：Tab 打开手机接单 → 靠近电动车按 E 上车 → 沿导航到商户 → 空格刹停、E 下车 → 步行靠近入口按 E 取餐 → 骑到收餐点、下车按 E 交付。

WASD：步行 / 驾驶；停车后 S 倒车
鼠标：转动镜头；Shift：步行奔跑
E：交互 / 上下车 / 取餐 / 交付；空格：刹车
Tab：手机；M：地图；Esc：暂停 / 音量 / 画质 / 退出
长按 R 两秒：脱困（有订单时加计 5 秒）

下车需车速不超过 3 km/h，取餐和交付需步行进入入口 2 米范围。
手机和地图不会暂停订单计时；Esc 暂停菜单会暂停世界。
回骑手驿站下车后可充电和购买升级，充电需等待 5 秒。
远离驿站且电量耗尽时，手机可确认救援；当前订单会失败，车辆返回驿站并充满电。

进度：%LOCALAPPDATA%\CityCourier\Saved\SaveGames
CourierProfile.sav 为主存档，CourierProfile.bak 为最近的有效备份。
关闭游戏后复制整个 SaveGames 文件夹即可备份。
余额、升级、设置自动保存；进行中的订单在重启时丢弃。
保存失败时请恢复磁盘空间或权限后点“重试保存”。主文件和备份均损坏时，界面提供两次确认的“创建新进度”（清空余额和升级）。

低 / 中 / 高三档画质；中档采用软件 Lumen，83% 内部分辨率重建至输出分辨率。硬件光追关闭。
本作是单人小街区配送首版，使用原创简化美术。无多人、战斗、警察、建筑内探索或昼夜天气系统。
